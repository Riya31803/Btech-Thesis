# Core-Periphery Structural Analysis of the World Trade Network

## Overview
This BTech thesis studies the structure of the global trade network using core-periphery modeling and network analysis. It examines trade connectivity, trade intensity, and changes in countries’ positions over a 10-year period.

The analysis covers 150+ countries, 24 economic parameters, and 9 commodity categories.

## Approach
- Prepared and organized trade data for network analysis.
- Applied the Borgatti-Everett model to identify core and peripheral economies.
- Used eigenvector centrality to rank countries by their trade influence.
- Applied community detection algorithms to identify trade clusters.
- Created visualizations to examine network structure and changes over time.

## Findings
- Identified dominant core economies and peripheral trade clusters.
- Examined shifts in countries’ trade influence and economic positioning.
- Analyzed connectivity patterns across commodity categories and years.
